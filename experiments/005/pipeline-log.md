# Журнал Gate A

| Фаза | Фактический результат |
| --- | --- |
| Направление | 1 проход, 3 арт-библии, 1 выбор после просмотра листа |
| Стоп-кадры | 1 запуск `npm run stills`, 23,663 с, включая 12,143 с сборки; 9 кадров по 1,164–1,427 с каждый вместе с выбором композиции |
| Контактный лист | 1 запуск `bash contact-sheet.sh`, время оболочки около 0,47 с |
| Движение | 1 запуск `npm run motion`, 14,275 с, включая 3,205 с сборки и 11,070 с на выбор композиции, рендер и кодирование |
| Правки после просмотра | 0, повторных видеорендеров 0 |
| Браузер и проверка | Chromium с viewport 360 × 640 проиграл файл до 4,00 с. `ffprobe -count_frames` и `ffmpeg -v error -xerror -i motion-proof.mp4 -f null -` прошли |
| Рабочий интервал | 3 мин 23 с от запуска чтения Issue #26 до записи этого журнала. Ожидание публикации и окончание фоновых тестов в интервал не входят |
| Токены и денежные затраты | Недоступны |

Один запуск Codex. На этапе вывода переиспользованы версии Remotion и React из Experiment 003, локальный Chromium и общий SVG-компонент рамки. Стоп-кадры и ролик «Диафрагмы» используют одну формулу движения. Два прочих направления зарегистрированы только как одиночные кадры. Text Lab не понадобился, так как исходной раскадровки для переноса не было и состояние задаётся одной формулой.

Команды воспроизведения приведены в [README](README.md). При исходном рендере использовались уже установленные пакеты 003 через временную локальную ссылку. Ссылка не входит в коммит. После вывода отдельно проверена установка из lockfile папки 005. Сборщик листа сообщил о недоступном кэше Fontconfig, но все девять подписей присутствуют. Внешние медиа, генераторы и новые пакеты для графики не использовались.
