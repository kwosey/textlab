# Шкала Gate A и сравнение

Оцени каждый наблюдаемый критерий как 0 (провал), 1 (частично или после подсказки), 2 (ясно с первого предъявления). Ставь «не проверено», если нет материала или зрителя. Каждый балл сопровождай кадром или ответом. Рубрика служит для решения о следующем проходе, а не для прогноза удержания.

| Что оцениваем | Способ проверки |
| --- | --- |
| Вовлечение | После одного просмотра спросить, какой момент вызвал желание смотреть дальше и почему. Записать дословный ответ. Самопроверка автора возможна, пометить её как таковую. |
| Хук до 2 с | Показать начало без контекста. Зритель называет объект и вопрос или видимое противоречие. |
| Причинность без звука | После отрывка спросить «что изменилось и почему?». Сначала без подсказки. В дополнительном диагностическом просмотре скрыть объясняющий текст, если это возможно без нового рендера. |
| Разнообразие | Сопоставить лист шотов. Отметить, где новый масштаб, композиция или темп открыли новую информацию. Удерживать ракурс допустимо, если он позволяет проследить процесс. |
| Читаемость на телефоне | При ширине просмотра около 360 CSS px и в зоне интерфейса проверить без паузы главный объект, его состояния и обязательные слова. Записать реальное устройство или режим эмуляции. |
| Повторное использование | Посчитать, какие решения и параметры перенесены буквально, какие интерпретированы, сколько заняла подготовка, валидация, ручная постановка и адаптер. |
| Измеренные затраты | Записать часы по стадиям и команды, число запущенных проходов, диапазон кадров, fps, размеры, среду и время вывода. Токены и деньги только из доступного учёта. |

Переход допустим при 2 по хуку, причинности и читаемости, подтверждённых просмотром Gate A. Фактическая ошибка, технический сбой, отсутствующий обязательный артефакт или оценка «не проверено» по одному из этих трёх критериев блокируют переход. Суммарный балл не компенсирует эти условия. Требуется отдельное человеческое одобрение.

## Сравнение с 003

Существующие контрольные материалы — три PNG и 222 кадра 540 × 960 при 30 fps. Превью 003 покрывает участок исходного времени 5,10–12,50 с без последней границы. Хук 003 можно сопоставить по кадру открытия, а оценка хука за первые две секунды как движения потребует отдельного эквивалентного отрывка. Финал полного фильма по этому комплекту сравнить нельзя. [Материалы 003](../003/gate-a/) · [Ревью 003](../003/review.md)

Для качественного сопоставления показывать одинаковые по функции кадры и равные по длительности отрывки на одном экране и без звука. Если темы различаются, отдельно отметить знакомство зрителей с каждой и считать вывод наблюдением о конкретных материалах. Сравнивать затраты на одинаковых границах работ. Общая длительность рендера разных разрешений или количества кадров описывает конкретные запуски.

Для причинного вывода о пользе playbook нужен контролируемый A/B с одним сценарным брифом, одинаковыми длиной, разрешением и бюджетом и двумя производственными протоколами. Дать материалы независимым зрителям без указания варианта, менять порядок показа, одинаково протоколировать ответы и полный труд. Для оценки пользы Text Lab нужен отдельный контроль с тем же брифом и той же режиссурой, где меняется только путь подготовки. Просмотр пары вариантов может подсказать правки. Рост удержания, снижение затрат и эффект самого playbook из текущих материалов не измерены.
