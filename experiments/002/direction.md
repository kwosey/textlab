# Режиссура

Монтажная частота 30 fps. Номера кадров с нуля, правая граница полуинтервала в CSV исключена. Пять Beats, нулевое перекрытие, четыре прямые склейки. Hold указан от конца Reveal до следующей склейки для текста, геометрия может продолжать движение.

| Время | Действие | Reveal / Hold |
| --- | --- | --- |
| 0.00–2.50 | «ПРОБКА. БЕЗ АВАРИИ?» читается на первом кадре. Три машины чуть сближаются, взгляд падает с вопроса на ряд. | 0.00 / 2.50 с |
| 2.50–5.50 | «Плотный поток. Машины вправо →». Все три проходят одинаковый путь вправо с постоянными расстояниями между ними. Это исходное состояние для сравнения. | 0.45 / 2.55 с |
| 5.50–10.00 | «Первый притормозил. Следом — ещё двое». Первая машина прекращает движение примерно в 6.06, следующая в 6.88, последняя в 7.70. Верхняя подпись выделяет действие, ниже можно проследить его от передней машины к задней. | 1.35 / 3.15 с |
| 10.00–13.00 | «Машины вправо → / ← Волна торможения». Два холодных силуэта идут вправо, тёплая черта над ними влево. Это схема направления фронта, сжатая по масштабу и времени. | 0.55 / 2.45 с |
| 13.00–16.00 | «Пробка-призрак. Без препятствия». Неподвижная группа остаётся над подписью. Пауза даёт время дочитать название. | 0.55 / 2.45 с |

Зритель проходит от видимого парадокса к механизму. Видеоряд помогает понять последовательность торможения, а противоположные стрелки закрепляют вывод. Простая геометрия здесь достаточна, поэтому отдельный кастомный кадр не понадобился.
